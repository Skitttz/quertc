

# 💬 Quertc 

O **Quertc** é um aplicativo de **chat web em tempo real**: crie conversas privadas ou grupos e troque mensagens direto do navegador.



## 🚀 Funcionalidades

* 💡 **Chat em tempo real** — mensagens instantâneas via WebSocket, sem atualizar a página.
* 🧑‍🤝‍🧑 **Conversas privadas e grupos** — converse a dois ou crie um grupo com várias pessoas.
* 🔔 **Mensagens não lidas** — a lista mostra a última mensagem de cada conversa e destaca as que você ainda não leu.
* 🖼️ **Perfil** — foto de perfil com upload de imagem.
* 🔒 **Autenticação** — cadastro e login com Clerk.
* 🎨 **Interface responsiva** — design adaptado para desktop e mobile.
* 📰 **Blog** — novidades do projeto publicadas a partir das issues com o label `blog`.
